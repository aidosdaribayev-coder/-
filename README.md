# 📊 Data Agent Server

Локальный ИИ-агент для анализа Excel файлов. Папка работает как база данных — просто кладёшь туда файлы, и агент их видит.

## 🚀 Быстрый старт

### 1. Установи Node.js
Скачай и установи с https://nodejs.org (версия 18+)

### 2. Установи зависимости
```bash
cd data-agent-server
npm install
```

### 3. Настрой API ключ
**Windows (PowerShell):**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-api03-..."
```

**Windows (CMD):**
```cmd
set ANTHROPIC_API_KEY=sk-ant-api03-...
```

**Mac/Linux:**
```bash
export ANTHROPIC_API_KEY="sk-ant-api03-..."
```

### 4. Запусти сервер
```bash
npm start
```

### 5. Открой в браузере
```
http://localhost:3000
```

## ✨ Возможности

- **📂 Автозагрузка** — файлы в папке `./data` автоматически загружаются
- **🔄 Автообновление** — изменения в файлах подхватываются автоматически
- **📑 Все листы** — читает все листы из каждого файла
- **🔍 Поиск** — ищет по всей базе данных
- **📊 Агрегация** — суммы, средние, группировки
- **🤖 AI-анализ** — задавай вопросы на естественном языке

## 🔌 API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/status` | Статус базы данных |
| GET | `/api/file/:name` | Данные файла |
| GET | `/api/search?q=текст` | Поиск по базе |
| GET | `/api/aggregate?column=X&operation=sum` | Агрегация |
| POST | `/api/ask` | Вопрос к AI |
| POST | `/api/rescan` | Пересканировать папку |

## ⚙️ Настройки

Переменные окружения:

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `ANTHROPIC_API_KEY` | API ключ Claude | - |
| `DATA_FOLDER` | Путь к папке с файлами | `./data` |
| `PORT` | Порт сервера | `3000` |

## 🛠 Решение проблем

**Ошибка "API ключ не настроен"**
→ Установи переменную ANTHROPIC_API_KEY перед запуском

**Файлы не загружаются**
→ Проверь формат (.xlsx, .xls, .csv)
→ Проверь что файл не открыт в Excel

**Порт занят**
→ Измени порт: `PORT=3001 npm start`
